# UnKraken/.github

Repo especial de la organización: su `CONTRIBUTING.md` y su plantilla de PR se aplican en todos los repos de UnKraken que no tengan los suyos.

| Fichero | Para qué |
|---|---|
| `CONTRIBUTING.md` | Protocolo común de trabajo: issues, ramas, commits, PR, versiones, IA |
| `pull_request_template.md` | Texto inicial de cada PR: `closes #`, qué cambia, cómo se ha probado y las comprobaciones |
| `plantilla/AGENTS.md` | Reglas para agentes de IA; se copia a la raíz de cada repo nuevo |
| `plantilla/CLAUDE.md` | Hace que Claude Code lea el `AGENTS.md` |

Los labels de Conventional Commits de este repo son el origen para los demás: `gh label clone UnKraken/.github --repo UnKraken/<repo>`.

Este repo es público: no pongas aquí código, datos de clientes ni credenciales.
